# Celestia

Front end of the [MLP Vector Club](https://github.com/MLP-VectorClub) website, a pnpm + Turborepo monorepo.

- [`apps/celestia`](apps/celestia): the Next.js app (see its README for production notes and `CLAUDE.md` for working notes)
- [`packages/config`](packages/config): shared `eslint` configurations
- [`packages/tsconfig`](packages/tsconfig): shared `tsconfig.json`s
- [`packages/ui`](packages/ui), [`packages/honeypot`](packages/honeypot): shared packages

Commands, from the repository root: `pnpm build`, `pnpm dev`, `pnpm lint`, `pnpm test`.
